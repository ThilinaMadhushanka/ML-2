## Overview

This Jupyter notebook demonstrates data manipulation and visualization using the `pandas` and `matplotlib` libraries in Python. It showcases essential skills in reading data, performing transformations, and visualizing insights using different types of plots.


<img src="https://github.com/Govindv7555/Govindv7555/blob/main/49e76e0596857673c5c80c85b84394c1.gif" width="100%" height="95px">

## Contents

The notebook includes:

- **Reading CSV files** using pandas  
- **Basic DataFrame operations** like `head()`, `info()`, `describe()`, and filtering  
- **Data cleaning** steps such as filling missing values and dropping columns  
- **Matplotlib plotting**:
  - Line plots
  - Bar charts
  - Pie charts
  - Histograms  
- **Group-by operations** and statistical summaries
